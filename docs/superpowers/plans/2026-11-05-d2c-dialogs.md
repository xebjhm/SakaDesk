# D2c Dialogs, Viewers and Menus Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move every dialog, viewer, menu and popover of SakaDesk onto one accessible dialog layer and the design-system tokens and primitives, without changing what they do, and remove the legacy theme fields nothing reads any more.

**Architecture:** Behaviour is locked first (Playwright e2e on the pinned big-room and blog fixtures plus vitest characterisation tests) on the unchanged code, and the zero-pixel baselines are re-captured with two intended masks. Then the foundation lands: tokens (status, viewer, decor, `ring-surface`, `accent-group`), button variants, a module-level dialog stack + `useDialog` hook behind the upgraded `Modal` primitive (focus trap and restore, top-most Escape, scroll lock, z-index per depth, `dialog` breadcrumbs), and `Menu`, `Switch`, `Input`, `Select`, `DialogStatus`. Dialogs then move onto it in groups (chat-menu dialogs, app dialogs, viewers, blog dialogs, menus, search, settings, entry-flow shells), each rewritten on tokens with its logic kept. Finally the legacy shells (`BaseModal`, `DetailModal`, `ModalStates`, `useModalClose`) and the unread `ServiceTheme` fields go.

**Tech Stack:** React 18 + TypeScript, Tailwind 3.3 with design-system tokens, tailwind-merge 2, lucide-react, vitest 4 + @testing-library/react + user-event, Playwright, FastAPI + pydantic + structlog, pytest.

Spec: `docs/superpowers/specs/2026-11-05-d2c-dialogs-design.md` (decision numbers below refer to its Decisions table).

### Adding i18n keys

Use this one-liner from `frontend/` (the locale files round-trip byte-identically through `JSON.stringify(…, null, 2)`); pass a JSON object `{locale: {"section.key": "value"}}` and avoid apostrophes in values:

```bash
node -e '
const fs = require("fs");
const add = JSON.parse(process.argv[1]);
for (const [code, entries] of Object.entries(add)) {
  const file = `src/i18n/locales/${code}.json`;
  const data = JSON.parse(fs.readFileSync(file, "utf8"));
  for (const [dotted, value] of Object.entries(entries)) {
    const [section, key] = dotted.split(".");
    data[section] = { ...(data[section] ?? {}), [key]: value };
  }
  fs.writeFileSync(file, JSON.stringify(data, null, 2) + "\n");
}' '<JSON>'
```

### Locating things in e2e before and after D2c

Before D2c most dialogs have no `role="dialog"` and menu items are plain buttons; after D2c dialogs are named dialogs and menu items are `menuitem`s. The locks therefore find **menu items by their text** (`page.getByText('Date Search', { exact: true })`), **dialogs without a role on the old code by their heading** (`getByRole('heading', { name: 'Settings' })`, an `h3` before and an `h2` after), and dialogs that already have the role (`BaseModal`, the profile card) by `getByRole('dialog', { name })`. Do not change these selectors in later tasks unless a step says so.

```ts
async function openCalendarAt(page: Page, monthLabel: string) {
  await page.getByTitle('More options').click()
  await page.getByText('Date Search', { exact: true }).click()
  const dialog = page.getByRole('dialog', { name: 'Date Search' })
  const prev = dialog.getByRole('button', { name: 'Previous month' })
  for (let i = 0; i < 80; i++) {
    if (await dialog.getByText(monthLabel, { exact: true }).isVisible()) return dialog

  }
  throw new Error(`calendar never reached ${monthLabel}`)
}
```

```ts
async function pinSettings(page: Page, saved: Record<string, unknown>[]) {
  await page.route((url) => url.pathname === '/api/settings', async (route) => {
    if (route.request().method() === 'POST') {
```

```ts
import { Z_INDEX } from '../../constants/zIndex';

/** One open dialog. `node` returns its frame (for the focus trap). */
export interface DialogEntry {
    readonly id: number;
    readonly node: () => HTMLElement | null;
    readonly dismissible: boolean;
}

let nextId = 1;
let stack: DialogEntry[] = [];
let savedOverflow: string | null = null;

/** Opens a dialog on top; the first one locks body scroll. */
export function pushDialog(entry: Omit<DialogEntry, 'id'>): DialogEntry {
    const full: DialogEntry = { ...entry, id: nextId++ };
    if (stack.length === 0) {
        savedOverflow = document.body.style.overflow;
        document.body.style.overflow = 'hidden';
    }
    stack = [...stack, full];
    return full;
}

/** Closes a dialog wherever it is in the stack; the last one restores body scroll. */
export function popDialog(entry: DialogEntry): void {
    if (!stack.some((e) => e.id === entry.id)) return;
    stack = stack.filter((e) => e.id !== entry.id);
    if (stack.length === 0) {
        document.body.style.overflow = savedOverflow ?? '';
        savedOverflow = null;
    }
}

export function isTopDialog(entry: DialogEntry): boolean {
    return stack.length > 0 && stack[stack.length - 1].id === entry.id;
}

/** z-index of a dialog: Z_INDEX.DIALOG for the first, one DIALOG_STEP higher per dialog below it. */
export function dialogZIndex(entry: DialogEntry): number {
    const depth = Math.max(0, stack.findIndex((e) => e.id === entry.id));
    return Z_INDEX.DIALOG + depth * Z_INDEX.DIALOG_STEP;
}

export function openDialogCount(): number {
    return stack.length;
}

/** Test helper: forget every dialog and unlock scroll. */
export function resetDialogStack(): void {
    if (stack.length > 0) document.body.style.overflow = savedOverflow ?? '';
    stack = [];
    savedOverflow = null;
}
```

```ts
import { useCallback, useEffect, useLayoutEffect, useRef, useState, type RefObject } from 'react';
import { Z_INDEX } from '../../constants/zIndex';
import { dialogZIndex, isTopDialog, popDialog, pushDialog, type DialogEntry } from './dialogStack';
import { logDialog, type CloseReason, type DialogLogId } from './dialogLog';

const TABBABLE =
    'a[href], button:not([disabled]), input:not([disabled]):not([type="hidden"]), select:not([disabled]), textarea:not([disabled]), [tabindex]:not([tabindex="-1"])';

export interface UseDialogOptions {
    isOpen: boolean;
    onClose: () => void;
    dismissible: boolean;
    frameRef: RefObject<HTMLElement>;
    initialFocusRef?: RefObject<HTMLElement>;
    logId?: DialogLogId;
}

/**
 * The dialog layer's behaviour (docs/superpowers/specs/2026-11-05-d2c-dialogs-design.md, "The dialog layer"):
 * stack entry + scroll lock, z-index by depth, initial focus and restore, Tab trap and
 * Escape for the top-most dialog only, and the `dialog` breadcrumb.
 */
export function useDialog({ isOpen, onClose, dismissible, frameRef, initialFocusRef, logId }: UseDialogOptions) {
    const [zIndex, setZIndex] = useState<number>(Z_INDEX.DIALOG);
    const entryRef = useRef<DialogEntry | null>(null);
    const reasonRef = useRef<CloseReason | null>(null);
    const onCloseRef = useRef(onClose);
    onCloseRef.current = onClose;

    const requestClose = useCallback((reason: CloseReason) => {
        reasonRef.current = reason;
        onCloseRef.current();
    }, []);

    // Stack entry, z-index, focus in / restore, breadcrumbs.
    useLayoutEffect(() => {
        if (!isOpen) return;
        const previous = document.activeElement instanceof HTMLElement ? document.activeElement : null;
        const entry = pushDialog({ node: () => frameRef.current, dismissible });
        entryRef.current = entry;
        reasonRef.current = null;
        setZIndex(dialogZIndex(entry));
        if (logId) logDialog(logId, 'open');
        (initialFocusRef?.current ?? frameRef.current)?.focus({ preventScroll: true });
        return () => {
            popDialog(entry);
            entryRef.current = null;
            if (logId) logDialog(logId, 'close', reasonRef.current ?? 'app');
            if (previous && document.contains(previous)) previous.focus({ preventScroll: true });
        };
        // eslint-disable-next-line react-hooks/exhaustive-deps -- one entry per open; dismissible/logId are read at open time
    }, [isOpen]);

    // Escape and Tab for the top-most dialog (bubble phase: handlers inside the dialog run first).
    useEffect(() => {
        if (!isOpen) return;
        const onKey = (e: KeyboardEvent) => {
            const entry = entryRef.current;
            if (!entry || !isTopDialog(entry)) return;
            if (e.key === 'Escape') {
                if (!dismissible || e.defaultPrevented || e.isComposing || e.keyCode === 229) return;
                if (document.fullscreenElement) return; // the browser leaves fullscreen
                e.preventDefault(); // claim it: the incoming-call overlay must not also decline
                requestClose('escape');
                return;
            }
            if (e.key !== 'Tab' || e.defaultPrevented) return;
            const frame = frameRef.current;
            if (!frame) return;
            const active = document.activeElement;
            if (active instanceof Element && active.closest('[role="menu"]')) return; // the menu handles Tab
            const items = Array.from(frame.querySelectorAll<HTMLElement>(TABBABLE));
            if (items.length === 0) {
                e.preventDefault();
                frame.focus();
                return;
            }
            const first = items[0];
            const last = items[items.length - 1];
            const inside = active instanceof Node && frame.contains(active);
            if (!inside || active === frame) {
                e.preventDefault();
                (e.shiftKey ? last : first).focus();
            } else if (!e.shiftKey && active === last) {
                e.preventDefault();
                first.focus();
            } else if (e.shiftKey && active === first) {
                e.preventDefault();
                last.focus();
            }
        };
        document.addEventListener('keydown', onKey);
        return () => document.removeEventListener('keydown', onKey);
    }, [isOpen, dismissible, frameRef, requestClose]);

    return { zIndex, requestClose };
}
```

```tsx
    footer?: React.ReactNode;
    /** 'sheet': light level-1 dialog. 'viewer': dark full-screen photo/video viewer. */
    tone?: 'sheet' | 'viewer';
    /** 'standard': header, body, footer. 'bare': children directly in the frame. */
    layout?: 'standard' | 'bare';
    placement?: 'center' | 'top';
    /** false: Escape and the backdrop do not close and there is no close button (ToS, setup, sync). */
    dismissible?: boolean;
    initialFocusRef?: React.RefObject<HTMLElement>;
    /** Frame classes (width, height). */
    className?: string;
    /** Standard body classes (padding). */
    bodyClassName?: string;
    /** Breadcrumb surface: logs `dialog` open / close. */
    logId?: DialogLogId;
    /** Keys for the dialog's own content (the viewer's ← / → / ↑ / ↓); Escape is the layer's. */
    onKeyDown?: React.KeyboardEventHandler<HTMLDivElement>;
}

/** Level 1 dialog on the dialog layer (docs/design/DESIGN_SYSTEM.md, "Dialogs"). */
export const Modal: React.FC<ModalProps> = (props) => (props.isOpen ? <OpenModal {...props} /> : null);

const OpenModal: React.FC<ModalProps> = ({
    onClose, title, 'aria-label': ariaLabel, labelledBy, closeLabel, headerExtra, children, footer,
    tone = 'sheet', layout = 'standard', placement = 'center', dismissible = true,
    initialFocusRef, className, bodyClassName, logId, onKeyDown,
}) => {
    const frameRef = useRef<HTMLDivElement>(null);
    const titleId = useId();
    const { zIndex, requestClose } = useDialog({ isOpen: true, onClose, dismissible, frameRef, initialFocusRef, logId });
    const named = title !== undefined && layout === 'standard' ? titleId : labelledBy;

    return createPortal(
        <div
            data-testid="modal-backdrop"
            className={cn(
                'fixed inset-0 flex justify-center p-4',
                placement === 'top' ? 'items-start' : 'items-center',
                tone === 'viewer' ? 'bg-viewer-scrim p-0' : 'bg-scrim',
            )}
            // 15vh from the top for the command-palette placement (an inline value: arbitrary padding classes are guarded).
            style={placement === 'top' ? { zIndex, paddingTop: '15vh' } : { zIndex }}
            onClick={(e) => {
                if (dismissible && e.target === e.currentTarget) requestClose('backdrop');
            }}
        >
            <div
                ref={frameRef}
                role="dialog"
                aria-modal="true"
                aria-labelledby={named}
                aria-label={named ? undefined : ariaLabel}
                tabIndex={-1}
                onKeyDown={onKeyDown}
                className={cn(
                    'outline-none',
                    tone === 'viewer'
                        ? 'relative flex h-full w-full items-center justify-center'
                        : 'flex max-h-full w-full max-w-lg flex-col overflow-hidden bg-sheet rounded-sheet shadow-sheet animate-reveal motion-reduce:animate-none',
                    className,
                )}
                onClick={tone === 'viewer' ? (e) => { if (dismissible && e.target === e.currentTarget) requestClose('backdrop'); } : undefined}
            >
                {layout === 'bare' ? children : (
                    <>
                        <div className="flex shrink-0 items-center gap-3 px-6 pb-2 pt-5">
                            {title !== undefined && (
                                <h2 id={titleId} className="min-w-0 flex-1 truncate text-title font-semibold text-primary">{title}</h2>
                            )}
                            {headerExtra}
                            {dismissible && closeLabel && (
                                <IconButton size="sm" aria-label={closeLabel} icon={<X />} onClick={() => requestClose('button')} />
                            )}
                        </div>
                        <div className={cn('min-h-0 flex-1 overflow-y-auto px-6 pb-6 text-body text-primary', bodyClassName)}>{children}</div>
                        {footer && <div className="flex shrink-0 items-center justify-end gap-2 px-6 pb-6">{footer}</div>}
                    </>
                )}
            </div>
        </div>,
        document.body,
    );
};
```

```tsx
import React, { useEffect, useRef } from 'react';
import { createPortal } from 'react-dom';
import { cn } from '../../utils/classnames';
import { Z_INDEX } from '../../constants/zIndex';

const ITEMS = '[role="menuitem"]:not([disabled]), [role="menuitemradio"]:not([disabled])';

/** Top-left of a box placed at (x, y), kept `pad` px inside the viewport. */
export function clampToViewport(x: number, y: number, size: { width: number; height: number }, pad = 8) {
    return {
        left: Math.max(pad, Math.min(x, window.innerWidth - size.width - pad)),
        top: Math.max(pad, Math.min(y, window.innerHeight - size.height - pad)),
    };
}

export interface MenuProps {
    'aria-label': string;
    onClose: () => void;
    /** Viewport point (context menus): portaled, fixed, clamped, above any dialog. */
    point?: { x: number; y: number };
    /** Size used to clamp a point menu. */
    estimatedSize?: { width: number; height: number };
    /** 'popover' for a menu the caller portals itself (player menus); default 'dropdown'. */
    layer?: 'dropdown' | 'popover';
    /** Focus returns here when the menu closes with focus inside it. */
    returnFocusRef?: React.RefObject<HTMLElement>;
    /** A mouse-down on these (the trigger) does not count as outside. */
    ignoreRefs?: React.RefObject<HTMLElement>[];
    className?: string;
    style?: React.CSSProperties;
    children: React.ReactNode;
}

/** Level-2 popover menu (docs/design/DESIGN_SYSTEM.md, "Menus"). */
export const Menu: React.FC<MenuProps> = ({
    'aria-label': ariaLabel, onClose, point, estimatedSize = { width: 200, height: 48 }, layer = 'dropdown',
    returnFocusRef, ignoreRefs, className, style, children,
}) => {
    const ref = useRef<HTMLDivElement>(null);
    const onCloseRef = useRef(onClose);
    onCloseRef.current = onClose;

    useEffect(() => {
        const menu = ref.current;
        menu?.focus({ preventScroll: true });
        const onDown = (e: MouseEvent) => {
            const target = e.target as Node;
            if (menu?.contains(target)) return;
            if (ignoreRefs?.some((r) => r.current?.contains(target))) return;
            onCloseRef.current();
        };
        // Capture phase: a menu inside a dialog closes before the dialog sees Escape.
        const onKey = (e: KeyboardEvent) => {
            if (e.key !== 'Escape' || e.defaultPrevented) return;
            e.preventDefault();
            onCloseRef.current();
        };
        document.addEventListener('mousedown', onDown);
        document.addEventListener('keydown', onKey, true);
        return () => {
            document.removeEventListener('mousedown', onDown);
            document.removeEventListener('keydown', onKey, true);
            if (menu && menu.contains(document.activeElement)) returnFocusRef?.current?.focus({ preventScroll: true });
            else if (document.activeElement === document.body) returnFocusRef?.current?.focus({ preventScroll: true });
        };
        // eslint-disable-next-line react-hooks/exhaustive-deps -- mount/unmount only
    }, []);

    const onKeyDown = (e: React.KeyboardEvent) => {
        if (e.key === 'Tab') { onCloseRef.current(); return; }
        if (!['ArrowDown', 'ArrowUp', 'Home', 'End'].includes(e.key)) return;
        e.preventDefault();
        const items = Array.from(ref.current?.querySelectorAll<HTMLElement>(ITEMS) ?? []);
        if (items.length === 0) return;
        const at = items.indexOf(document.activeElement as HTMLElement);
        const next =
            e.key === 'Home' ? 0
            : e.key === 'End' ? items.length - 1
            : e.key === 'ArrowDown' ? (at + 1) % items.length
            : (at <= 0 ? items.length - 1 : at - 1);
        items[next].focus();
    };

    const position: React.CSSProperties = point
        ? { position: 'fixed', ...clampToViewport(point.x, point.y, estimatedSize), zIndex: Z_INDEX.POPOVER }
        : { zIndex: layer === 'popover' ? Z_INDEX.POPOVER : Z_INDEX.DROPDOWN };

    const menu = (
        <div
            ref={ref}
            role="menu"
            aria-label={ariaLabel}
            tabIndex={-1}
            onKeyDown={onKeyDown}
            className={cn('flex min-w-44 flex-col rounded-card bg-card p-1 shadow-card outline-none', className)}
            style={{ ...position, ...style, left: point ? position.left : style?.left, top: point ? position.top : style?.top }}
        >
            {children}
        </div>
    );
    return point ? createPortal(menu, document.body) : menu;
};

export interface MenuItemProps extends Omit<React.ButtonHTMLAttributes<HTMLButtonElement>, 'role'> {
    icon?: React.ReactNode;
    /** Selected option (speed, loop): `text-group-strong`, the selected-text role. */
    selected?: boolean;
    destructive?: boolean;
    /** One of a set of options: `menuitemradio` with `aria-checked`. */
    radio?: boolean;
}

export const MenuItem = React.forwardRef<HTMLButtonElement, MenuItemProps>(
    ({ icon, selected = false, destructive = false, radio = false, className, children, type = 'button', ...rest }, ref) => (
        <button
            ref={ref}
            type={type}
            role={radio ? 'menuitemradio' : 'menuitem'}
            aria-checked={radio ? selected : undefined}
            tabIndex={-1}
            className={cn(
                'flex w-full items-center gap-2 rounded-pill px-3 py-2 text-left text-small',
                'transition-colors duration-fast ease-standard hover:bg-sunken focus-visible:bg-sunken focus-visible:outline-none',
                'disabled:pointer-events-none disabled:text-muted',
                destructive ? 'text-status-danger' : selected ? 'font-semibold text-group-strong' : 'text-primary',
                className,
            )}
            {...rest}
        >
            {icon && (
                <span aria-hidden="true" className={cn('flex h-4 w-4 shrink-0 items-center justify-center', !destructive && !selected && 'text-secondary')}>
                    {icon}
                </span>
            )}
            {children}
        </button>
    ),
);
MenuItem.displayName = 'MenuItem';

export const MenuLabel: React.FC<{ children: React.ReactNode }> = ({ children }) => (
    <div role="presentation" className="px-3 pb-1 pt-2 text-caption text-muted">{children}</div>
);

/** Space between groups of items: never a line (docs/design/DESIGN_SYSTEM.md, Do / Don't). */
export const MenuSeparator: React.FC = () => <div role="separator" className="h-2" />;
```
